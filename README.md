# home-automation-orchestrator

## 目標
「アレクサ、いってきます」
↓
電気を消す。さらに、テレビがONならテレビを消す。テレビがOFFの場合は電気だけ消す。
つまり、テレビのON/OFFを状態として管理し、常体に応じた操作をしたい

現在使っているテレビは赤外線リモコンの信号を覚えさせてハブから赤外線を送信している。電源はトグルなので、現在がON/OFFのどちらにあるかを考慮せず反転する。
このため、オートメーションに組み込みずらい。
電源プラグを使って、テレビの消費をモニタリングし、電力が～W以上ならA動作、そうでなければB動作という感じ

プラグの電力に応じてデバイスを操作する機能は"オートメーション"という名前で公式アプリから利用可能。しかし、アレクサからこのオートメーションを呼び出すことはできないので(条件にかかわらずデバイスを操作させる機能である”シーン”と″オートメーション”は別物であり、シーンはアレクサから呼び出し可能。なんとややこしい)、アレクサに指示を出し、そこから条件分岐させることができない。このため、Switchbot公式アプリで完結させるのは断念。

そこで、Switchbotが提供するAPI経由でテレビプラグの電圧をフィードバックして、テレビのON/OFFを判定するようにする。このアレクサスキルを例えばウェイクワード「ただいま」にすると、「アレクサ、ただいま」で条件分岐付きのデバイス操作ができるのではないか？

## 方針
APIからは、公式アプリから作ったシーンを実行することができる。複数のシーンを作っておき、条件に応じたシーンを実行することで条件分岐を実現。
### 例
- いってきますA(テレビがついていない)：電気を消す。
- いってきますB(テレビがついている)：電気を消す。テレビを消す。
テレビに接続されたプラグの電力がA以下なら行ってきますAを実行。そうでなければいってきますBを実行
